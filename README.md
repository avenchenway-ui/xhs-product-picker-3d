# 拾知 · 小红书虚拟产品选品助手

纯静态单文件展示网站，无构建工具、无第三方资源请求。直接打开 index.html 即可使用。

## 功能

- CSS 3D 卡片堆叠、悬浮动画、鼠标跟随倾斜和玻璃材质。
- 移动端响应式、键盘操作、减少动态效果偏好支持。
- 五轮访谈表单，前后切换，整理工作底稿并导出 Markdown。
- 准确展示隐性知识、付费场景、案例验证、产品标题、交付骨架、产品矩阵与7天计划。

## 能力边界

页面依据用户指定能力制作。现有本地目录中的两项 Skill 状态为待下载，生财 MCP 在制作时需要重新认证，因此未声称加载其最新原始文件。
表单使用固定结构整理用户输入，没有接入 AI 或实时案例检索。案例明确标为假设，实际需求需要访谈与验证。回答仅在页面内存中保留，不上传。

## GitHub Pages

将 index.html 与 README.md 放入公开仓库 main 分支根目录，在 Settings → Pages 选择 Deploy from a branch → main → /(root)。
本站不分发 Skill 源包。
